# 🤝 Contributing to Lockpad

Thanks for considering a contribution — Lockpad is a solo designer's, actively-maintained side project, and outside contributions are warmly welcome.

## 🧰 Before you start

- For anything beyond a small fix (typo, obvious bug), open an issue first to discuss the approach before writing code. It saves a rewritten PR later.
- Check open issues and pull requests so effort doesn't get duplicated.

## 🔨 Making a change

1. Fork the repo and branch off `main`.
2. Keep each PR focused — one fix or feature at a time is much easier to review than a bundle of unrelated changes.
3. Match the existing code style already used in `backend/` and `frontend/`.
4. Test your change locally (see the README's "Developing" section) before opening a PR.
5. Write a clear PR description: what changed, and why.

## 📮 Reporting bugs

Open a GitHub issue with steps to reproduce, what you expected to happen, and what actually happened. Include your install method (the install script, or Docker Compose by hand) — it's usually relevant to self-hosted bugs.

## 🙏 Code of conduct

Be respectful and patient. This is a small project maintained in someone's spare time.
